## Abstract
A reactor that runs for weeks with nobody beside it is only as good as its own record, so every reading here shows when it has stopped being true.
BR-01 has grown B. subtilis five times, and the longest run logged 434 hours at 22 °C with no sample drawn. No result rests on one instrument: a reference beam that never sees the culture separates lamp drift from growth, wall shear is computed twice, from pressure and from flow, the photometer was calibrated against a known TiO₂ dose, and the field leaf sensor was scored against an air probe breathing the same air. That layer gave 26.7 hours of warning before the OD channel failed, and it comes with the 434-hour batch as its test case for any team with an optical sensor. A growth forecast fixed by hash before the current run is scored on it. Both interfaces run live on this page. The loop is not closed, and almost every result rests on one run.
